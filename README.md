# EduPilot — образовательное пространство

Рабочее приложение на русском языке с дизайном Interactive Constellation. В репозитории есть локальная версия Next.js с SQLite и серверная сборка для Sites с D1 и R2. Интерфейс, API, модели Prisma и образовательные инструменты общие для обеих версий.

## Быстрый запуск

Рекомендуется Node.js 22 LTS и npm. Локальные проверки также выполнены на Node.js 20.20.1. Для сборки Sites требуется Node.js не ниже 22.13.0. Устанавливайте зависимости той же версией Node.js, которой будете запускать локальное приложение: SQLite содержит нативный модуль.

```sh
npm install
npm run setup
npm run dev
```

Откройте http://127.0.0.1:3000. Setup создаёт .env из .env.example, приватную директорию вложений и SQLite-базу, затем применяет миграции. Повторный запуск безопасен. Аккаунт создаётся через форму регистрации; демонстрационных паролей и аккаунтов в production нет.

```sh
npm run build
npm start
npm test
npm run typecheck
```

В этой Windows-среде для Next.js выбран Webpack: установленный Turbopack завершался ошибкой при запуске дочернего процесса. Это отражено в командах dev и build.

## Что реализовано

- Лендинг и отдельные формы регистрации/входа. Серверная авторизация с Argon2id, случайными сессиями в HttpOnly/SameSite cookie, CSRF-проверкой Origin, ограничением попыток и сменой пароля. На HTTPS устанавливается Secure.
- Роли учителя и ученика. Переключатель вида интерфейса не повышает серверные права ученика.
- Рабочее пространство, адаптивная боковая панель, светлая/тёмная тема, настройки фона и предпочтения в базе данных.
- Чат с историей, поиском, переименованием, удалением, повторным ответом, копированием, Markdown, подсветкой кода и формулами. Файлы можно прикреплять, но текстовый чат не утверждает, что анализирует их.
- Редактируемые планы уроков, рабочие листы, контрольные с вариантами и ключами, конспекты. Время этапов шаблона урока совпадает с общей длительностью.
- Менеджер материалов с поиском, фильтрами, сортировкой, переименованием, копированием и удалением с подтверждением. Автосохранение и оптимистичная блокировка через version.
- Редактор презентаций и сценариев видео: слайды 16:9, добавление/перемещение/удаление, текст, фон, изображения PNG/JPEG, показ слайдов, длительность сцен и предварительное прослушивание голосом браузера.
- Настоящие DOCX, PDF с кириллицей и редактируемые PPTX. Ключи ответов выдаются только в экспорте владельца-преподавателя при явном включении.
- Приватные вложения JPG/PNG/WEBP/PDF/DOCX с проверкой сигнатур и ограничением размера. Ручная проверка работ, комментарии и подтверждение оценки. Изображения и DOCX можно передать ИИ только при отдельно включённых возможностях.
- Классы, одноразовые приглашения с истечением через 24 часа, выдача материалов, сдача работ и ручное оценивание. Графики Recharts строятся по сохранённым оценкам; фиктивной статистики нет.
- Тесты с вариантами ответа, серверным сроком попытки, подсчётом результата и историей. Ответы преподавательских материалов скрываются на сервере. Открытые ответы в самопроверке сравниваются с ключом; развёрнутые работы оценивает преподаватель.

## Подключение текстового ИИ

В .env:

```dotenv
AI_API_KEY=ваш_ключ
AI_BASE_URL=https://api.openai.com/v1
AI_MODEL=gpt-4.1-mini
AI_MODE=auto
```

Перезапустите сервер. Режим auto выбирает MockAIProvider без ключа и LiveAIProvider при наличии конфигурации. Режим mock принудительно оставляет демонстрационные ответы, live без ключа сообщает ошибку. Успех реального провайдера проверяется при запросе; наличие ключа не гарантирует его валидность.

API-ключ существует только на сервере и не передаётся в браузер. В размещённой версии задавайте эти же параметры в серверном окружении Sites. В UI нет формы отправки секретов.

Интерфейс AIProvider расположен в lib/ai.ts. Генераторы используют типизированную структуру sections и Zod-валидацию с одним повтором при ошибке формата. Запросы имеют таймаут и лимиты. Демо-ответы отмечены явно и не являются анализом загруженных файлов.

### Изображения, документы и видео

- AI_SUPPORTS_VISION=true включайте только для модели с поддержкой image_url. Проверка изображения использует серверный адаптер; её вывод предварительный и не выставляет подтверждённую оценку.
- AI_SUPPORTS_DOCUMENTS=true включает извлечение текста DOCX и передачу его текстовой модели. Это не универсальный PDF/OCR-движок.
- PDF доступен для ручной проверки. OCR рукописей и серверный анализ PDF отдельно не подключены.
- SpeechSynthesis даёт предварительное прослушивание, а не скачиваемую озвучку.
- В lib/media-adapters.ts есть TTSProvider, OpenAICompatibleTTSProvider, VideoAssemblyProvider и LessonVideoPipeline. Для финального MP4 нужны реальный кодировщик, синхронизация аудио и сцен, очереди задач и серверный TTS-провайдер. Они не активированы и не отображаются как работающая видеогенерация. FFmpeg в проверенном окружении отсутствует.

## Архитектура

```text
app/                    Next.js App Router, защищённая оболочка, API
components/             интерфейс, редакторы, чат, классы, shadcn/ui
components/constellation/ ParticleEngine и Canvas-компонент
lib/domain.ts           Zod-схемы и редактируемые образовательные шаблоны
lib/security.ts         пароли, сессии, CSRF, лимиты
lib/database.ts         Prisma: локальный SQLite или D1
lib/ai.ts               MockAIProvider и LiveAIProvider
lib/storage.ts          StorageProvider: локальная директория или R2
lib/export.ts           DOCX, PDF, PPTX
prisma/                 схема и локальные миграции
drizzle/                те же SQL-миграции для D1 / Sites
tests/                  серверные интеграционные тесты Vitest
e2e/                    проверки Playwright
build/                  интеграция сервера Sites
```

Переиспользуемые визуальные компоненты отделены от движка частиц и серверной логики. ParticleEngine использует пространственную сетку, ResizeObserver, ограничение DPR, адаптацию количества точек, остановку в неактивной вкладке и prefers-reduced-motion. При отключении Canvas приложение продолжает работать.

## Данные и безопасность

База локальной версии: prisma/edupilot.db. Приватные файлы: private-storage/; они не находятся в public/. Делайте резервные копии этих двух путей вместе. .env, базы, вложения и состояние Wrangler исключены из Git и архива исходников.

Все операции с пользовательскими записями выполняются сервером после проверки сессии и владельца. Код ученика не получает ключи ответов преподавателя. При конфликте версии сервер возвращает 409. Уже оценённую сдачу нельзя незаметно заменить. Загруженный текст рассматривается как недоверенные данные, HTML пользователя не исполняется. Размер файла ограничен 10 МБ, количество файлов в операции интерфейса — 5.

SQLite подходит для локального запуска. Для PostgreSQL потребуется сменить datasource, адаптер и SQL-миграции; UI и доменная структура от этого не зависят. Для S3 реализуйте тот же StorageProvider, что используется локальным хранилищем и R2.

## Адаптивное обучение и исследовательские материалы

Раздел **Учебная траектория** (`/learning`) добавляет5заданий диагностики и10практики по четырём темам. Банк72задания работает без внешнего API. Фиксированный режим и адаптация используют одинаковые эталоны; правила3верных/2ошибки и пороги50/80 настраиваются серверным config сессии преподавателя. Это детерминированные правила, не обученная ML-модель. Класс сохраняется как контекст объяснений, не преобразует банк под все11классов.

`/learning/progress` — собственная история, ошибки и журнал решений; `/learning/analytics` — только ученики своих классов. Демо-сессии выбираются явно и исключаются из обычных метрик. `/learning/library` — черновики, ручная проверка, одобрение/отклонение; сохранённая правка возвращает draft. Демо-вопросы даже после одобрения не попадают в обычный пул.

Примените добавочную миграцию командой `npm run setup`. Старые базы не удалять. Для локального Worker отдельно один раз примените `drizzle/0002_learning.sql` тем же способом, что миграции ниже. Физическая схема mastery не переименована: ORM observedMastery/observationJson хранят наблюдённый префикс, а публичный журнал вычисляет согласованные checkpoints по (createdAt,id). Аналитика читает ID порциями40 для D1.

```sh
node research/run-technical.mjs
node node_modules/tsx/dist/cli.mjs research/run-simulation.ts
node research/build-report.mjs
npm run test:e2e -- e2e/learning.spec.ts e2e/workspace.spec.ts
```

Отчёты: `docs/PROJECT_AUDIT.md`, `RESEARCH_REPORT.md`, `EXPERIMENT_RESULTS.md`, `DEMO_SCENARIO.md`, `JURY_QA.md`, `COMPETITION_READINESS.md`. Машинные результаты — `research/results/`. План будущей апробации, согласия и пустые формы — `research/`. Симуляции не являются данными учеников и не подтверждают эффективность. LiveAI без ключа не испытан; при AI_MODE=live отсутствие ключа даёт явную ошибку, без скрытого fallback. Профиль аккаунта не отправляется модели, но свободные учебные тексты требуют ручного контроля ПДн.

Playwright настроен на установленный Edge и отдельный временный профиль. Для другой ОС замените channel в playwright.config.ts или установите Chromium командой npx playwright install chromium и уберите channel.

Тесты Vitest используют отдельную временную SQLite-базу и удаляют её после выполнения. Браузерный сценарий создаёт аккаунт с префиксом e2e- в локальной базе, чтобы проверить регистрацию и сохранность данных. Не запускайте этот сценарий против реальных production-данных.

## Сборка для Sites

Sites использует тот же App Router через Vinext. В .openai/hosting.json сохраняются идентификатор существующего сайта и привязки DB/BUCKET. Облачный Prisma-клиент использует WebAssembly и адаптер D1; локальный нативный SQLite-адаптер в Worker не попадает.

```sh
npm run db:generate
npm run sites:build
```

Команда db:generate сверяет миграции Prisma с их D1-копиями и добавляет новые. Уже применённый SQL не переписывается. Для новой схемы сначала создайте новую миграцию Prisma, затем синхронизируйте её. Локальная SQLite-база и D1 независимы.

Для отдельной локальной D1-проверки после сборки примените каждую ещё не применённую SQL-миграцию:

```sh
node --import ./scripts/sites-env.mjs ./node_modules/wrangler/bin/wrangler.js d1 execute DB --local --config dist/server/wrangler.json --persist-to .wrangler/state --file drizzle/0000_edupilot.sql
node --import ./scripts/sites-env.mjs ./node_modules/wrangler/bin/wrangler.js d1 execute DB --local --config dist/server/wrangler.json --persist-to .wrangler/state --file drizzle/0001_quiz_sessions.sql
node --import ./scripts/sites-env.mjs ./node_modules/wrangler/bin/wrangler.js dev --config dist/server/wrangler.json --local --persist-to .wrangler/state --port 4173
```

Проверка Worker: установите HOSTED_PREVIEW=1 и EDUPILOT_TEST_URL=http://127.0.0.1:4173, затем выполните npm run test:e2e -- e2e/hosting.spec.ts. Нативная публикация Sites применяет миграции к размещённой D1-базе и сохраняет приватный доступ сайта.

Требуется дальнейшая проверка с реальным AI_API_KEY: ключ не был предоставлен, поэтому платные API не вызывались. Расширенные макеты документов, произвольный WYSIWYG-дизайн и полноценный видеомонтаж не являются частью текущего редактора разделов и слайдов.
