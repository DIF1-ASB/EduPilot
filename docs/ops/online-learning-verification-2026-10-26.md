# EduPilot: локальная приёмка онлайн-контрольных и конспектов

Дата итогового прогона: 26 октября 2026 года. Все девять задач утверждённого плана реализованы локально. Ветка `feat/edupilot-adaptive-research` сохранена без merge/push. Это не отчёт о публикации: рабочий сайт, его провайдер, база и прежний Sites не изменялись.

## Результат

- Преподаватель создаёт онлайн-тест по теме, предмету и классу. По умолчанию десять вопросов с четырьмя ответами, одним ключом и одним баллом. Перед выдачей нужны просмотр, подтверждение и успешное сохранение именно текущей редакции.
- Ученик выбирает ответы, получает серверную оценку и отдельную историю контрольных в прогрессе. Порядок вариантов устойчив при перезагрузке. Пустая ручная сдача не раскрывает решения; действуют лимит попыток и преподавательская политика показа ответов.
- Генерация сохраняется как фоновая задача. Выход со страницы не уничтожает результат, отмена и восстановление не дублируют материалы. Автоматической выдачи группе нет.
- Новый конспект — цельная статья с заголовками, примерами и математикой. Старые форматы остаются читаемыми и редактируемыми. Word/PDF сохранены для конспектов и других разрешённых материалов, но отключены для контрольных.
- Исторические данные не пересоздаются. Миграции только добавляют очередь, порядок вариантов попытки и предметный контекст назначения.

Изолированный harness создаёт временную SQLite, локальный синтетический ИИ и отдельный worker. Использовались только искусственные пользователи `example.invalid`. Рабочая база и настоящий ключ NVIDIA не открывались. Запросов к NVIDIA в этой реализации: **ноль**. Эти проверки доказывают работу интерфейсов и контрактов, но не достоверность реальных ответов модели.

Миграционная проверка сравнивает HMAC-манифесты всех прежних таблиц/полей и байты вложений до/после миграции и после восстановления резервной копии. Старая активная смешанная попытка сохраняет ID, черновик и таймер, затем завершается с ожиданием ручной проверки. Все проверки выполняются на временных искусственных данных, не на копии реальных пользовательских данных.

Визуальная приёмка 23 октября: все страницы обычного конспекта (PDF 2, DOCX 3) и расширенного математического примера (PDF 3, DOCX 3), кириллица, дроби, степени, подписи стрелок, списки и переносы просмотрены. 26 октября заново просмотрены браузерные снимки результата контрольной и мобильного конспекта. Синтетические тексты не являются демонстрацией качества модели.

## Независимая проверка и единственный проход исправлений

Проверка диапазона `0dd92b2..c9553e0` начата отдельным рецензентом; после остановки из-за лимита и недоступности его модели завершена заменой рецензента до изменения реализации. Повторной проверки после исправлений не было. Подтверждены три существенные проблемы, все исправлены с наблюдавшимися RED→GREEN-регрессиями:

1. Ошибка PATCH, незавершённое автосохранение или повторное подтверждение могли открыть выдачу старой серверной редакции. Теперь сохранение возвращает явный результат, выдача привязана к сохранённому снимку и сбрасывается при редактировании. Три настоящих браузерных сценария сначала упали, после исправления прошли.
2. Длинная формула могла уменьшиться до нечитаемой линии. Чрезмерно широкое выражение теперь отклоняется с просьбой разбить его; обычные формулы остаются изображениями в DOCX/PDF.
3. Markdown-код с отступом мог переписываться как формула. Защита использует исходные позиции кодовых узлов CommonMark, включая табуляцию, списки и цитаты, без пересериализации текста.

Все исправления проверены полным набором 280 тестов и общим браузерным прогоном.

Отложенное небольшое замечание: интерфейс демошаблона недостаточно явно сообщает, что даже заполненный вручную `demo:true` не включается в обычный прогресс. Фильтр демоданных сохранён намеренно; автоматической смены происхождения материала при подтверждении нет.

## Решения исполнителя и их цена

Полный список в хронологическом порядке:

1. Выделены чистые общие математические подсказки и независимый онлайн-промпт: устранён импорт серверной Prisma-цепочки в клиент. Цена — отдельное регрессионное покрытие старого и нового промпта.
2. Отменённый upstream удерживает слот до остановки/восстановления lease, чтобы отмена не обходила предел двух вызовов. Цена — временно занятый слот.
3. Языковой контроль ограничен русскоязычной математикой/биологией, не запрещает другие алфавиты универсально. Цена — остальные предметы требуют человеческой проверки языка.
4. При несовместимом native-модуле временно использовались Node 20 для регрессий и Node 24 для проверок сборки. Финальная приёмка перенесена полностью на официальный проверенный Node 22.23.3 с пересобранным better-sqlite3. Цена — необходимость согласованных runtime и native-модуля; системный Node не заменялся.
5. Vitest ограничен четырьмя worker без ослабления таймаутов/проверок: снята случайная перегрузка fixture. Цена — возможный более долгий CI на многоядерной машине.
6. Новые назначения сохраняют предметный контекст атомарно, старые явно используют текущие метаданные. Цена — прежние названия нельзя достоверно восстановить задним числом.
7. Проверочные документы создавались настоящими экспортерами приложения, а не отдельным построителем; Python/Poppler использовались для QA. Цена — более узкая изоляция зависимостей для синтетической интеграционной проверки.
8. Из-за отсутствия LibreOffice в bundled Windows runtime использовалась приватная распаковка официального проверенного пакета, без установки настольной программы. Цена — отличие локального QA-инструментария от bundled macOS/Linux.
9. Прежний lint-долг не исправлялся широким рефакторингом. Цена — общий lint остаётся красным до отдельной задачи.
10. Прерванная итоговая проверка завершена заменой рецензента до fix pass. Цена — восстановление части контекста и возможное пересечение чтений, не дополнительный post-fix review.
11. Реальное качество/задержки NVIDIA не оценивались внешними вызовами. Цена — отдельная предметная оценка перед выбором рабочего провайдера.
12. VPS и восстановление настоящей базы не проверялись вне разрешённого локального объёма. Цена — отдельная репетиция и согласование перед публикацией.
13. Повторно подтверждено решение не расширять итоговое review на прежний lint-долг. Цена — 217 прежних ошибок остаются.
14. Для новых jobs и экспорта формул на D1/cloud сохранены явные ограничения возможностей. Цена — отдельная реализация этих функций для облачного runtime.
15. Подтверждение ключей не снимает `demo:true`: происхождение материала не меняется неявно. Цена — ручное заполнение демошаблона само по себе не включает его в обычный прогресс; требуется отдельный согласованный сценарий превращения в обычную работу.
